# NexusTavern

Модульное приложение для ролевого отыгрыша (RP) с ИИ на базе **React + Vite** и чистого **Node.js** ядра со 100% совместимостью пользовательских данных SillyTavern (`data/default-user`).

Подробное описание архитектуры, структуры папок, требований совместимости и регламента пошаговой разработки находится в файле **[PROJECT.md](./PROJECT.md)**.
